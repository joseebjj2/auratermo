Propósito: analizar registros reales de temperatura y precipitación de ciudades
chilenas, comparar días sobre umbrales elegidos y explorar un desplazamiento
hipotético de temperatura. NO es un pronóstico meteorológico para 2035.

Modalidad: API REST con requests.get() y DataFrame de pandas.
Respaldo: CSV opcional descargable/generable en Internet, mediante
"python descargar_respaldo.py" y la pestaña "Datos y Excel".

Fuente: Open-Meteo Historical Weather API
https://open-meteo.com/en/docs/historical-weather-api

INSTRUCCIONES
1. Instalar Python 3.11 o superior.
2. Abrir una terminal en esta carpeta.
3. Ejecutar: pip install -r requirements.txt
4. Ejecutar: streamlit run app.py
5. Elegir ciudades/año en la barra lateral y explorar las pestañas.
6. Para respaldo real: python descargar_respaldo.py (requiere Internet).
7. Si falla la API, subir el archivo CSV generado al componente de respaldo.

Publicación: subir la carpeta completa al repositorio de GitHub;
crear aplicación en Streamlit Community Cloud, seleccionar app.py.
